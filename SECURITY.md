## Security Model & Boundaries

This repository is the **project index / profile** for sora (mo9652962-ai) — it
contains only Markdown documentation and links. There is no executable code,
no build pipeline, and no runtime surface.

1. **No Credential Storage:** No secrets, tokens, private keys, or `.env` files
   exist in this repository.
2. **No Execution Boundary:** This repository contains documentation only. Nothing
   is executed, installed, or served from it.
3. **No Network Boundary:** There are no outbound requests, telemetry, or
   analytics of any kind.

## Reporting a Vulnerability

If you believe one of the linked projects has a security issue, please report it
in **that project's** repository rather than here.

For issues specific to this index repository:

- Please **do not** create a public GitHub Issue.
- Submit details privately via GitHub Private Vulnerability Reporting.
- We will acknowledge receipt within 48 hours.
