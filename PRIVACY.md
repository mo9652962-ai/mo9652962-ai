# Privacy Policy

**Last Updated:** 2026-10

This repository is the **project index / profile** for sora (mo9652962-ai) —
a curated list of open-source projects spanning local-first CAD/EDA tooling,
cross-platform mini-programs, an English practice app, and an AI second brain.

We uphold strict local-first and zero-telemetry data protection principles.

## 1. Local Processing & Data Ownership

- This repository is **documentation only** — it contains no executable code and
  processes no user data.
- Each linked project follows its own privacy policy; every one of them is built
  local-first with user data remaining the sole property of the user.

## 2. Network Boundaries

- **Zero Telemetry:** No analytics SDKs, tracking pixels, or phone-home routines
  exist in this repository.
- There are no outbound requests of any kind from this repository.

## 3. Credential Handling

- No secrets, API keys, or credentials exist in this repository.
- Individual projects document their own credential handling in their respective
  `PRIVACY.md` files.

## 4. Contact & Disclosure

For security issues or questions regarding this policy, refer to
