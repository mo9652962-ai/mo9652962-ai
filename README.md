## 🚀 精选项目

### 📚 [墨题 · 英语刷题机](https://github.com/mo9652962-ai/english-multiple-choice-practice-machine)

开源的本地优先英语学习工作台（考研 / 四六级 / 高考）：题库自由导入（Word / ESQ）、整卷与随机练习、FSRS 词汇复习、错题迭代、学习诊断，可选 AI 精讲 / 作文精批 / 口语陪练。**Windows / Web / Android 三端**，内置 647 道真题 + 7,958 词核心词库。

`Vue 3` `FastAPI` `SQLite` `Capacitor` `FSRS` `GPL-3.0`

### 🧠 [Second Brain — AI Agent 第二大脑](https://github.com/mo9652962-ai/second-brain)

持续自我进化的全中文 Obsidian 知识库：AI Agent **七大自举系统**、硬件 / PCB 全链路知识、学术写作工作流，每 30 分钟自动同步。不是死的笔记集合，是会从错误中学习、固化 Skill 的活系统。

`Obsidian` `AI Agent` `Hermes` `知识管理` `MIT`

### 🎯 [Quiz Assistant](https://github.com/mo9652962-ai/quiz-assistant)

本地优先题库 CLI：JSON / CSV 导入、分层模糊匹配、练习与 SM-2 复习、OCR 辅助填答、SHA-256 备份恢复。刻意只用 Python 标准库 + SQLite，Windows 离线友好。

`Python` `SQLite` `CLI` `SM-2`

### 🏭 [波峰焊治具自动出图系统](https://github.com/mo9652962-ai/wave-soldering-fixture-designer)

基于真实 Gerber / Excellon 文件的波峰焊载具自动分析、几何生成与 AutoCAD DXF 出图，把制造业治具设计从手工描图变成一条命令。

`Python` `Gerber` `DXF` `CAD` `制造业`
