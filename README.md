## 🚀 精选项目

### 🛡 [Agent Audit — AI Agent 环境安全审计](https://github.com/mo9652962-ai/agent-audit)

一条命令审计本机 AI Agent 环境：供应链投毒、明文密钥、端口暴露、git 泄漏、依赖漏洞、MCP server 攻击面——7 项只读检查，判定标准对照 **OWASP / NSA CSI / MCP 官方安全指南**。有 [GitHub Marketplace Action](https://github.com/marketplace/actions/agent-audit) 可作 CI 门禁，已获 [OpenSSF Best Practices](https://www.bestpractices.dev/projects/15101) 徽章。

`Python` `CLI` `OWASP` `MCP` `Windows 优先` `MIT`

### 📚 [墨题 · 英语刷题机](https://github.com/mo9652962-ai/english-multiple-choice-practice-machine)

开源的本地优先英语学习工作台（考研 / 四六级 / 高考）：题库自由导入（Word / ESQ）、整卷与随机练习、FSRS 词汇复习、错题迭代、学习诊断，可选 AI 精讲 / 作文精批 / 口语陪练。**Windows / Web / Android 三端**，内置 647 道真题 + 7,958 词核心词库，[自动更新分发仓](https://github.com/mo9652962-ai/epm-releases)随行。

`Vue 3` `FastAPI` `SQLite` `Capacitor` `FSRS` `GPL-3.0`

### 🧠 [Second Brain — AI Agent 第二大脑](https://github.com/mo9652962-ai/second-brain)

持续自我进化的全中文 Obsidian 知识库：AI Agent **七大自举系统**、硬件 / PCB 全链路知识、学术写作工作流，每 30 分钟自动同步。不是死的笔记集合，是会从错误中学习、固化 Skill 的活系统——上面两个项目的[千轮研究](https://github.com/mo9652962-ai/second-brain)都从这里长出来。

`Obsidian` `AI Agent` `Hermes` `知识管理` `MIT`

### 🔧 [ESQ Builder MCP — 题库包工具链](https://github.com/mo9652962-ai/esq-builder-mcp)

把题库包工具链固化为 5 个 MCP 工具：构建（自动修复机械坑）→ 校验（双轨）→ 上传发布，外加词表解析与热点词统计。`uvx` 一行接入。

`MCP` `FastMCP` `Python` `uvx` `MIT`

### 🧹 [Skill Maintenance MCP — 技能库维护](https://github.com/mo9652962-ai/skill-maintenance-mcp)

把技能维护的铁律（修订前备份 / 写入后损坏扫描 / 决策留痕 / 体检）固化成 5 个 MCP 工具——机械环节不再依赖 prompt 纪律。

`MCP` `FastMCP` `Python` `MIT`

### 🎯 [Quiz Assistant — 题库 CLI](https://github.com/mo9652962-ai/quiz-assistant)

[墨题](https://github.com/mo9652962-ai/english-multiple-choice-practice-machine)的轻量 CLI 前身：JSON / CSV 导入、分层模糊匹配、练习与 SM-2 复习、OCR 辅助填答。刻意只用 Python 标准库 + SQLite，Windows 离线友好。

`Python` `SQLite` `CLI` `SM-2`

### 🏭 [波峰焊治具 AI 设计助手](https://github.com/mo9652962-ai/wave-fixture-ai)

输入 PCB Gerber 文件 → 自动生成波峰焊治具工程图（DXF/STL）：2D 出图、3D 预览、元件干涉分析、自然语言参数调整——把制造业治具设计从手工描图变成一条命令。

`Python` `Gerber` `DXF` `CAD` `制造业`
